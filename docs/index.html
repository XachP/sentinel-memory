Sentinel Memory

A deterministic guardian for live Suilend loans on Sui mainnet. Every run it reads the chain through Tatum, recalls what it learned from Walrus Memory, and decides HOLD / WATCH / ESCALATE / ABSTAIN. It remembers which price feeds lied, which of its own arguments were right, and which alarms were false, so tomorrow's decision differs from today's for reasons you can audit. There is no LLM in the decision path, and every decision replays bit for bit.
